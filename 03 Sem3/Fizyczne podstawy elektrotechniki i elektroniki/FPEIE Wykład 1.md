# Część merytoryczna
### Podział ze względu na technologię:
- *SSI* ( Small Scale Integration ) → mała skala integracji ( do 100 tranzystorów ) - np. pojedyncze bramki logiczne.
- *MSI* ( Medium Scale Integration ) → średnia skala integracji ( do 1000 tranzystorów ) - np. liczniki, rejestry
- *LSI* ( Large Scale Integration ) → duża skala integracji ( do 10 000 tranzystorów ) - np. proste mikroprocesory, układy pamięci
- *VLSI* ( Very Large Scale Integration ) → miliony tranzystorów np. nowoczesne procesory CPU i GPU
- *ULSI* ( Ultra Large Scale Integration ) → miliardy tranzystorów np. najnowsze, najbardziej złożone układy
