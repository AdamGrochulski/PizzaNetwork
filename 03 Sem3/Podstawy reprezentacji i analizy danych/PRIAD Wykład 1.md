# Informacje
### **Forma zajęć :**
- Wykład 9 modułów ( 2 - 4 godziny lekcyjne każdy )


### **Zaliczenie zajęć :**
- Egzamin pisemny w sesji - 25 pkt ( zal 13 pkt )
- Egzamin ustny w sesji - 15 pkt ( bez progu, nieobowiązkowy )
- Sprawdzian z części ćwiczeniowej - 20 pkt ( zal 11 pkt )
- Projekt ( sprawozdanie + prezentacja ) - 20 + 20 = 40 pkt ( zal 11 + 11 = 22 pkt )

- sprawdzian : 16, 18, 19 ,12
